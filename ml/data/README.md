# Training Data

Place your training CSV here as `training_data.csv`.

## Format

```csv
text,label
"Donate $5 to save democracy! actblue.com/mycandidate",1
"Your Amazon package has shipped",0
```

- `text` — the SMS body
- `label` — `1` for political/donation spam, `0` for legitimate

## Building the dataset

1. Export your vault CSV from the app (Vault screen -> share icon)
2. Label each row (the app already classified them as spam, so most will be `1`)
3. Add legitimate SMS examples labeled `0` (delivery notifications, 2FA codes,
   personal messages, bank alerts, etc.)
4. Save as `training_data.csv` in this directory
5. Run `python train_model.py` from the `ml/` directory

A starter dataset of ~200 synthetic examples is generated by `train_model.py`
if `training_data.csv` does not exist.
